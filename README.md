# Automated Mark Entry System

## Project Overview

An automated mark entry system that uses Convolutional Neural Networks (CNN) and OpenCV to recognize handwritten numerical marks from answer sheets.

## Technologies Used

* Python
* TensorFlow 
* OpenCV
* NumPy
* Openpyxl

## Main Features

* Handwritten digit recognition
* Image preprocessing and digit segmentation
* Camera-based image capture
* Excel output for recognized digits

## Current Status

The project demonstrates the core digit recognition pipeline. Further improvements are required to enhance recognition accuracy on real-world handwritten marks.
